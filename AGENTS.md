# Contribution Rules

- For feature work, create a dedicated feature branch before making changes.
- Use branch names in the form `rya/<feature-name>` for features, and
  `ryan/<fix-or-performance-name>` for fixes or performance work.
- Split work into focused, logical commits as each feature piece is completed.
- Follow the patterns and conventions already established in this repository.
- Before handing work off, run the best relevant validation available for the
  affected project (for example, its tests, linting, type checks, or build).
- Keep actionable work in `backlog/README.md`. Read it before starting work,
  move an item to **In progress** while working, and update its status,
  handoff notes, and validation results before handing off.
- Add newly discovered follow-up work to `backlog/README.md`; do not overwrite
  unfinished work recorded by another agent.
